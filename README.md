A top-down stealth game for the [make.fun](https://make.fun) best stealth game bounty. You are the courier: steal all 14 data chips across 3 hand-built floors — Warehouse Row, The Courtyard, The Vault — and reach the green EXIT gate unseen. Guards patrol with vision cones, grow suspicious, chase, and investigate; bushes hide you, crates block their sight, and sneaking (SHIFT) keeps you quiet.

## Play

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD / arrows to move, SHIFT to sneak, R to restart a floor, M to mute. No build step, no network requests, no libraries: plain Canvas 2D and procedural WebAudio.
